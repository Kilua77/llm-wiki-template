# ECMTCP Acronyms List - Digest

This source provides a **comprehensive catalog** of acronyms and abbreviations used throughout the ECMTCP/FLC technical documentation.

## Key Points

The document contains **over 100 acronyms** covering various technical domains:

### Networking and Telecommunications
- AAA, ASAP, ASGI, DCN, DCC, DTA, ES, FEC, GDCI, GMPLS, gNMI, IETF, IOM, IPC, IP, LAN, MTP, NE, NNI, NRT, OAMP, OCH, ODU, OMS, OSPF, OS, OTS, PCS, PTP, TTI, TTP, UNI, WDM
- Network protocols: TL1, TLS, SSL, SSH, REST, gRPC
- Network elements: SLTE, SLC, SC, TLC, NE

### Software and Development
- ACE, AGL, API, CLI, CSS, GUI, IDE, JSON, XML, XSLT, YAML, YANG
- Version control: VOB (ClearCase), Git
- Build tools: Albie, wpack
- Databases: RDBMS, SQL
- Operating systems: RHEL, LTS, WRL (Wind River Linux)

### Hardware and Platforms
- AVX, BBE, BBU, BEC, CPU, GPU, HDD, PID, POSIX, SSE4, SSD
- Platforms: ESCT2000, EASE2000, ESCT3000, XFLC1000, CFLC(Z)

### Optical Technologies
- COTDR, OCH, ODU, OGPI, OID, ORB, PCS, PRBS

### Security
- AAA (Authentication, Authorization, Accounting), SA (Service Affecting), NSA (Non Service Affecting), SID (System IDentifier)
- SSL, TLS, SSO, TCA (Threshold Crossing Alarm)

### Testing and Quality
- APT (Active Problem Table), CPL (Customer Patch Level), NRT (Non Regression Tests), QF (Quality Factor)

### Standards and Organizations
- ASN (Alcatel Submarine Networks), IETF, IANA, RFC

### ECMTCP/FLC Specific

- Interfaces: GLI (Generic Layer Interface), SLI (Specific Layer Interface)

- Agents: SDNAGENT, TL1AGENT

## Document Structure

The source is organized as:
1. **Main list**: Alphabetical listing of acronyms with their expansions
2. **Footnote section**: Repeats the same acronyms with the `[ACRONYM]: Expansion` format for Markdown footnote compatibility

## Notable Patterns

- Many acronyms are **domain-specific** to submarine network systems (SLTE, SEPS, LNS, etc.)
- Some acronyms have **multiple meanings** in different contexts (e.g., OS = Operator Specific, OS = Operating System)
- The list includes both **standard industry terms** (API, CPU, IP, etc.) and **project-specific terms** (FLC, ECMTCP, GOL, SOL, etc.)
