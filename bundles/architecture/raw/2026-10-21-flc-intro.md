# FLC Documentation

This documentation provides an overview of the FLC (First Level Controller) system, its architecture, and development processes.

## FLC Overview

The FLC team develops and maintains embedded applicative software for a first-level controller system. As the main controller, the FLC software ensures:

- Configuration and persistence of network equipment, cables, and transmission parameters (output powers, optical spectrum, bitrates, client interfaces, etc.)
- Monitoring: alarm and failure reporting, measurements, performance tracking, traffic protection
- Software upgrades, etc.

Based on a robust object-oriented architecture, the FLC software comprises several million lines of C++ code developed over multiple decades.

While new features continue to be developed, the system maintains a significant amount of legacy code that requires ongoing modernization.

## Development Environment

Each developer works with a Linux environment (physical or virtual machines). The development workflow includes:

- Documentation written in Markdown format
- Local documentation server for preview
- Standard development tools and practices

## Network Resources

The development environment utilizes several network resources for documentation, deliveries, and maintenance data. These include:
