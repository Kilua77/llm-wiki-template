L'agent TL1 (Telecommunication Language One Agent) est une unité logicielle version v9-4-0-23-0.

Il gère les fichiers binaires (bin*), les bibliothèques TL1 (libTL1*), les bibliothèques AGTGLI (libAGTGLI*), 
libMtcpSecurity.so, ainsi que divers fichiers de configuration.

L'installation organise les fichiers sous ecmtcp/app/AOL/TL1/.
