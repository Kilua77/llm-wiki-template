L'interface SLI (Service Layer Interface) est définie comme une unité logicielle version v9-4-0-8-0.

Elle fournit les bibliothèques suivantes : libSLIgol.so, libSLIsol.so, libSLImsgcommon.so, 
libSLImsgdata.so, libSLImsgbase.so, et libSLImsgsdh.so.

Ces bibliothèques implémentent l'interface SOL (Service Order Logic) et les messages associés.
