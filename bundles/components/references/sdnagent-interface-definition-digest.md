L'agent SDN (Software Defined Network Agent) est une unité logicielle version v9-4-0-20-0.

Il comprend plusieurs services et bibliothèques : SdnAgent (binaire), libGliService.so, 
libGliYangMapperService.so, libModelUpdaters.so, libNotificationService.so, libSDNAGENT.so, 
libYangModelService.so, libAaaService.so, libDatabaseService.so.

L'installation crée une structure de répertoires complète sous ecmtcp/app/AOL/SDN/.
